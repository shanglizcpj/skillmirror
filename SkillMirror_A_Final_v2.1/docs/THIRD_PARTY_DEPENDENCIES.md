# 第三方依赖披露

本包不要求商业 API，未配置 LLM 也能运行完整 Demo。直接 Python 依赖如下；验证环境版本来自 2026-08-14 本次封版安装。

| 依赖 | requirements 版本 | 验证版本 | 用途 | 许可证标识 |
|---|---|---:|---|---|
| FastAPI | 0.141.1 | 0.141.1 | HTTP API / OpenAPI | MIT |
| httpx | 0.28.1 | 0.28.1 | FastAPI 测试客户端依赖 | BSD-3-Clause |
| jsonschema | 4.26.0 | 4.26.0 | Draft 2020-12 Schema 校验 | MIT |
| Pydantic | 2.13.4 | 2.13.4 | API 请求模型 | MIT |
| pytest | 9.1.1 | 9.1.1 | 自动测试 | MIT |
| Uvicorn | 0.52.3 | 0.52.3 | ASGI 开发服务 | BSD-3-Clause |

直接依赖已固定为封版验证版本。间接依赖及其许可证仍应在正式发布时用锁文件/SBOM 再次生成和审核。

如成员 B 接入商业/闭源模型，必须另行披露供应商、模型版本、调用环节、费用、数据保留、权限、可替代性和失败 fallback。本包的 `llm` 是可注入调用接口，不绑定任何供应商。

正式开源前，团队还需选择项目自身许可证并确认题目、文档、品牌素材和成员贡献的权利。本交付包不擅自代表团队作许可证决定。
