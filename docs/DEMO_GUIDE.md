# SkillMirror Demo Guide

## 1. Demo目标

通过一个固定Python Challenge，完整展示SkillMirror如何：

- 选择需要验证的能力
- 观察学习者编程过程
- 运行可信隐藏测试
- 提供渐进式提示
- 生成可验证Evidence
- 更新Skill Score和Confidence
- 推荐下一项Challenge

完整闭环：

```text
Start Challenge
→ Coding
→ Run Tests
→ Get Hint
→ Submit Assessment
→ Evidence
→ Skill Update
→ Next Challenge
